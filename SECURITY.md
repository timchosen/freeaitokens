# Security

Please report vulnerabilities privately, not in a public issue:
[open a private report](https://github.com/timchosen/freeaitokens/security/advisories/new).

Useful to include: what is affected (the `freeaitokens` package, the desktop app, the catalogue service or the website), the version, and the steps to reproduce.

You should get a reply within a week. Fixes go into the latest version of the package and the desktop app.

In scope, for example: keys or the local token leaking, the local endpoint being reachable from other machines or web pages, a tampered catalogue being accepted, or the install scripts doing something other than installing the app.

Not in scope: weaknesses in the AI providers themselves, and limits or terms set by those providers.
