What the install script does

Pasting a command from a website into Terminal means trusting that website. Here is everything the FreeAITokens installer does, and its full source.

In plain words

  1. Works out whether you have a Mac, Linux or Windows computer.
  2. Downloads the latest FreeAITokens app from its public GitHub releases.
  3. Mac: puts the app in your Applications folder (replacing an older copy) and opens it. Linux: saves it as ~/.local/bin/freeaitokens-app. Windows: runs the normal installer.
  4. Deletes the downloaded file. It changes nothing else: no admin password, no settings, no other software.

The whole script sits inside one function that runs only at the very end, so a download cut off halfway does nothing.

To read it before running it: curl -fsSL https://{{domain}}/install | less
