Qué hace el script de instalación

Pegar en Terminal un comando sacado de una página web significa confiar en esa página. Aquí tienes todo lo que hace el instalador de FreeAITokens, y su código completo.

En palabras sencillas

  1. Averigua si tu ordenador es un Mac, Linux o Windows.
  2. Descarga la última app de FreeAITokens desde sus versiones públicas en GitHub.
  3. Mac: pone la app en tu carpeta Aplicaciones (reemplazando una copia anterior) y la abre. Linux: la guarda como ~/.local/bin/freeaitokens-app. Windows: ejecuta el instalador normal.
  4. Borra el archivo descargado. No cambia nada más: ni contraseña de administrador, ni ajustes, ni otro software.

Todo el script está dentro de una sola función que se ejecuta solo al final, así que una descarga cortada a medias no hace nada.

Para leerlo antes de ejecutarlo: curl -fsSL https://{{domain}}/install | less

Mac y Linux: /install

{{installScript}}

Windows: /install.ps1

{{installPs1}}
