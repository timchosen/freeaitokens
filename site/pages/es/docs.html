Línea de comandos

Con Node.js 20 o posterior no necesitas la app:

npx freeaitokens               # start the local endpoint
npx freeaitokens add           # add a free provider key (guided)
npx freeaitokens list          # providers, key status, what is left today
npx freeaitokens remove <id>   # delete a stored key

O instálalo una vez: npm install -g freeaitokens. La dirección local escucha solo en 127.0.0.1:4949 y necesita el token local del mensaje de inicio. La app y el comando comparten claves y ajustes.

Los lanzadores solo afectan a esa sesión y no escriben nada en la configuración de tu herramienta. setup opencode añade un proveedor junto a los que ya tienes y guarda una copia de seguridad; --undo la restaura.

Qué hace

  • Elige un modelo por solicitud. Solo modelos que puedan atenderla: contexto suficiente, uso de herramientas cuando la herramienta lo necesita, imágenes cuando hay imágenes. Prefiere los mejores modelos que han sido rápidos y fiables para ti, y se queda con el mismo modelo durante una conversación salvo que otro sea claramente mejor.
  • Cambia de modelo si falla. Ante un límite de uso, un error del servidor o un tiempo de espera agotado, prueba con el siguiente modelo antes de que tu herramienta note nada. Si todo está ocupado y la capacidad vuelve en menos de 30 segundos, espera; si no, te avisa de cuándo.
  • Lleva la cuenta de los límites gratuitos por proveedor, modelo y clave, por minuto y por día, y se corrige con los límites que informan los proveedores.
  • Habla cinco formatos: OpenAI chat completions, Anthropic Messages (Claude Code), OpenAI Responses (Codex), Gemini (Gemini CLI) y Ollama (/api/chat).
  • Mantiene al día la lista de proveedores, firmada y comprobada antes de usarla, así que los modelos gratuitos nuevos llegan sin actualizar.

Más allá del chat

La misma dirección acepta las rutas de OpenAI para embeddings (/v1/embeddings), completados simples (/v1/completions), imágenes (/v1/images/generations), texto a voz (/v1/audio/speech), transcripción (/v1/audio/transcriptions) y vídeo (/v1/videos), cada una enviada a un proveedor gratuito que la ofrezca, con el mismo cambio automático y los mismos límites.

  • Gratis hoy: embeddings (Gemini, OpenRouter, SEA-LION, Cloudflare, OVH), completados (Cerebras, OpenRouter, OVH), imágenes (Cloudflare Flux, OpenRouter), texto a voz (Groq, OpenRouter, Cloudflare), transcripción (Groq, Cloudflare, OVH). Ningún proveedor ofrece vídeo gratis todavía.
  • Embeddings: los vectores de modelos distintos no se pueden comparar. Envía el nombre del modelo que te dio la respuesta (por ejemplo gemini-embedding-001) y las solicitudes siguientes se quedan en él.

Claves de pago y opciones

Las claves de pago pueden quedar por debajo de las gratuitas como último recurso: se usan solo cuando ningún modelo gratuito puede atender la solicitud, cada solicitud de pago se imprime, y hay un tope diario.

OpciónQué hace
--port <n>Puerto de la dirección local (por defecto 4949)
--free-onlyNunca usar claves de pago
--paid-cap <n>Máximo de solicitudes de pago por día (por defecto 200)

Aún no compatible

  • Cursor: envía el tráfico de direcciones personalizadas a través de sus propios servidores, que no pueden llegar a una dirección local.
  • La app de ChatGPT: no puede usar una dirección personalizada.
  • Edición de imágenes, traducción de audio, voz en tiempo real.
  • Las herramientas de apps conectadas (MCP) y la búsqueda web de Codex no se pasan a los modelos gratuitos: añaden más contexto del que aceptan los modelos gratuitos.
