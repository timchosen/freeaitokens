Command line

With Node.js 20 or newer you don't need the app:

npx freeaitokens               # start the local endpoint
npx freeaitokens add           # add a free provider key (guided)
npx freeaitokens list          # providers, key status, what is left today
npx freeaitokens remove <id>   # delete a stored key

Or install it once: npm install -g freeaitokens. The endpoint listens on 127.0.0.1:4949 only and needs the local token from the startup banner. The app and the command share keys and settings.

Launchers only affect that one session and write nothing to your tool's config. setup opencode adds a provider next to your existing ones and keeps a backup; --undo restores it.

What it does

  • Picks a model per request. Only models that can handle it: enough context, tool calling when the tool needs it, images when there are images. It prefers better models that have been fast and reliable for you, and stays on the same model through a conversation unless another is clearly better.
  • Fails over. On a rate limit, server error or timeout it tries the next model before your tool sees anything. If everything is busy and capacity returns within 30 seconds it waits; otherwise it tells you when.
  • Tracks free limits per provider, model and key, by the minute and by the day, and corrects itself from the limits providers report.
  • Speaks five formats: OpenAI chat completions, Anthropic Messages (Claude Code), OpenAI Responses (Codex), Gemini (Gemini CLI) and Ollama (/api/chat).
  • Keeps an up-to-date provider list, signed and checked before use, so new free models arrive without an update.

Not only chat

The same endpoint takes the OpenAI routes for embeddings (/v1/embeddings), plain completions (/v1/completions), images (/v1/images/generations), text to speech (/v1/audio/speech), transcription (/v1/audio/transcriptions) and video (/v1/videos), each sent to a free provider that offers it, with the same failover and limits.

  • Free today: embeddings (Gemini, OpenRouter, SEA-LION, Cloudflare, OVH), completions (Cerebras, OpenRouter, OVH), images (Cloudflare Flux, OpenRouter), text to speech (Groq, OpenRouter, Cloudflare), transcription (Groq, Cloudflare, OVH). No provider offers free video yet.
  • Embeddings: vectors from different models can't be compared. Send the model name the response gave you (for example gemini-embedding-001) and later requests stay on it.

Paid keys and options

Paid keys can sit below the free ones as a last resort: used only when no free model can serve the request, each paid request is printed, with a daily cap.

OptionWhat it does
--port <n>Port for the local endpoint (default 4949)
--free-onlyNever use paid keys
--paid-cap <n>Most paid requests per day (default 200)

Not supported yet

  • Cursor: it sends custom-endpoint traffic through its own servers, which can't reach a local address.
  • The ChatGPT app: it can't use a custom endpoint.
  • Image editing, audio translation, realtime voice.
  • Codex's connected-app (MCP) tools and web search are not passed to free models: they add more context than free models accept.
