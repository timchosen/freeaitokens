设置

只需两步：添加几个免费密钥，然后让你的 AI 工具连到 FreeAITokens。

1. 添加免费密钥

{{keyless}} 家服务商完全不需要账号。你每多加一个免费账号，总额度就多一份。

  1. 点击菜单栏或系统托盘里的 FreeAITokens 图标，选择 Add a provider（添加服务商）。
  2. 挑一家服务商。应用会打开它的注册页面，并明确告诉你该点哪里。
  3. 创建一个免费账号，复制它给你的密钥，粘贴到应用里。应用会先检查密钥，再保存。

适合先从这几家开始：Cerebras 和 Groq（免费额度大）、OpenRouter（一键连接）和 Google Gemini。

密钥保存在你的电脑上（有钥匙串的话就存在钥匙串里），只会发送给它所属的服务商。请使用你自己的账号，每家服务商一个。为什么这很重要。

2. 连接你的工具

你的本地地址是 http://127.0.0.1:4949。如果某个工具需要填这些信息，应用菜单里有 Copy endpoint（复制地址）和 Copy local token（复制本地令牌）。

Claude Code

通过 FreeAITokens 启动它：

npx freeaitokens claude

只有这一次会话使用免费模型；正常运行 claude 时用的还是你自己的账号。

Codex

npx freeaitokens codex

Gemini CLI

npx freeaitokens gemini

OpenCode

npx freeaitokens setup opencode

然后选择模型 freeaitokens/free。加上 --undo 可以恢复你原来的设置。

VS Code、Zed、JetBrains

会打印出该粘贴到编辑器设置里的确切内容：

npx freeaitokens setup vscode

把 vscode 换成 zed 或 jetbrains 即可。

Cline、Continue、Roo Code、Crush

npx freeaitokens setup cline

也可以把 cline 换成该工具自己的名字。

Kilo Code、Qwen Code、Goose、Aider

npx freeaitokens aider

或者用 kilo、qwen、goose。

其他任何应用

只要它允许你设置自定义的 OpenAI 地址：

  • Base URL http://127.0.0.1:4949/v1
  • 模型 free
  • API 密钥：应用菜单里的 Copy local token

上面的命令需要 Node.js。如果你没有，可以让你的 AI 来做这一步，或者到 nodejs.org 下载 Node.js。

暂不支持

Cursor 会让自定义地址的流量经过它自己的服务器，而那些服务器连不到你的电脑。ChatGPT 应用则完全不能使用自定义地址。
