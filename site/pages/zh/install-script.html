安装脚本做了什么

把网站上的命令粘贴到 Terminal 里运行，意味着你信任这个网站。下面是 FreeAITokens 安装程序所做的全部事情，以及它的完整源码。

通俗地说

  1. 判断你用的是 Mac、Linux 还是 Windows 电脑。
  2. 从公开的 GitHub 发布页下载最新的 FreeAITokens 应用。
  3. Mac：把应用放进“应用程序”文件夹（替换旧版本）并打开。Linux：保存为 ~/.local/bin/freeaitokens-app。Windows：运行常规的安装程序。
  4. 删除下载的文件。除此之外它不会改动任何东西：不要管理员密码，不改设置，也不装其他软件。

整个脚本被包在一个函数里，只在最后一刻才运行，所以下载到一半被中断时，什么也不会发生。

想在运行前先读一读：curl -fsSL https://{{domain}}/install | less

Mac 和 Linux：/install

{{installScript}}

Windows：/install.ps1

{{installPs1}}

这两个文件也都在源代码仓库里。发现问题？请私下报告。
