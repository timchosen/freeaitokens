简单说：FreeAITokens 不收集任何关于你的信息。可选的付费同步只保存它读不到的加密数据。

本网站

  • 没有 Cookie，没有数据分析，没有广告，没有追踪脚本。
  • 网站托管在 Cloudflare 上，由它负责处理连接，并保留标准的技术日志（例如 IP 地址），用于运行和保护服务。
  • 页面会向 GitHub 查询项目的星标数，所以 GitHub 会看到来自你浏览器的这个请求。

应用和命令行

  • 你的密钥保存在你的电脑上（有钥匙串的话就存在钥匙串里），只会发送给它所属的服务商。
  • 你的提示词和回答直接在你的电脑和 AI 服务商之间传递，不会经过任何 FreeAITokens 的服务器。各服务商如何处理这些内容，由它们自己的隐私政策决定；可能把内容用于训练的服务商会有标记。如果你开启同步,保存的对话也会以加密形式存储,详见下文。
  • 服务商列表每天会几次从 Cloudflare 上的 FreeAITokens 服务下载。这个请求不包含任何关于你或你使用情况的信息；和所有网络请求一样，Cloudflare 会看到你的 IP 地址。
  • 没有遥测。应用不会上报使用情况、错误或任何其他数据。
  • 本地地址只在你自己的电脑上监听，并且需要令牌，所以其他设备和网站无法使用它。

同步(可选,付费)

如果你购买同步,FreeAITokens 在 Cloudflare 上的服务器会保存:

  • 你的对话和密钥,已加密 ——在发送前就在你的电脑上加密。服务器从来没有你的口令或打开它们的密钥,因此读不到它们。
  • 每个同步项:一个随机 id、大小、版本号和修改时间。
  • 你的同步密钥的打乱形式(哈希),从不保存密钥本身。
  • 你付款邮箱的打乱形式(带密钥的哈希),只用于让“把密钥发给我”表单找到你的密钥。邮箱本身不保存。
  • 你的方案、到期时间,以及 Stripe 为你的付款和客户记录分配的 id。

同步由 Stripe 销售并收款,因此你的付款信息和邮箱会按照 Stripe 的隐私政策 交给 Stripe。方案到期,或付款被退款或争议时,你的加密数据会在 90 天后删除。
