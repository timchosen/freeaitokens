命令行

装有 Node.js 20 或更新版本的话，你不需要应用：

npx freeaitokens               # start the local endpoint
npx freeaitokens add           # add a free provider key (guided)
npx freeaitokens list          # providers, key status, what is left today
npx freeaitokens remove <id>   # delete a stored key

或者一次性安装：npm install -g freeaitokens。本地接口只监听 127.0.0.1:4949，并且需要启动横幅里显示的本地令牌。应用和命令行共用同样的密钥和设置。

启动器只影响那一次会话，不会往你工具的配置里写任何东西。setup opencode 会在你已有的服务商旁边添加一个，并保留备份；用 --undo 可以恢复。

它做了什么

  • 每个请求选一个模型。只选能胜任的模型：上下文够长、工具需要时支持工具调用、有图片时支持看图。它偏好对你来说又快又稳的更好的模型，并且在一次对话中会一直用同一个模型，除非另一个明显更合适。
  • 自动切换。遇到限流、服务器错误或超时，它会在你的工具察觉之前就换下一个模型。如果所有模型都忙，而额度会在 30 秒内恢复，它会等待；否则会告诉你什么时候能恢复。
  • 追踪免费额度，按服务商、模型和密钥分别统计，精确到每分钟和每天，并根据服务商返回的额度信息自行校正。
  • 支持五种格式：OpenAI chat completions、Anthropic Messages（Claude Code）、OpenAI Responses（Codex）、Gemini（Gemini CLI）和 Ollama（/api/chat）。
  • 保持服务商列表最新，列表带签名，使用前会校验，所以新的免费模型不用更新应用就能用上。

不止对话

同一个接口还支持 OpenAI 的这些路径：向量嵌入（/v1/embeddings）、普通文本补全（/v1/completions）、图片（/v1/images/generations）、文字转语音（/v1/audio/speech）、语音转文字（/v1/audio/transcriptions）和视频（/v1/videos）。每种请求都会发给提供该功能的免费服务商，同样有自动切换和额度限制。

  • 目前免费的有：向量嵌入（Gemini、OpenRouter、SEA-LION、Cloudflare、OVH）、文本补全（Cerebras、OpenRouter、OVH）、图片（Cloudflare Flux、OpenRouter）、文字转语音（Groq、OpenRouter、Cloudflare）、语音转文字（Groq、Cloudflare、OVH）。目前还没有服务商提供免费视频。
  • 向量嵌入：不同模型生成的向量不能互相比较。请发送响应里告诉你的模型名（例如 gemini-embedding-001），之后的请求就会一直用它。

付费密钥与选项

付费密钥可以排在免费密钥之后，作为最后的备选：只有在没有免费模型能处理请求时才会用，每次付费请求都会打印出来，并且有每日上限。

选项作用
--port <n>本地接口的端口（默认 4949）
--free-only从不使用付费密钥
--paid-cap <n>每天最多的付费请求数（默认 200）

全部 {{providers}} 家服务商

它们加起来每月最多公布 {{monthly}} 个免费 token。这个数字是把各家公布的免费额度加总得到的，只公布了请求次数限制的，按每次请求 2,000 个 token 计算；其中大部分来自少数几份大额度，而且你只有为每家服务商都添加密钥才能用上。没有公布额度的服务商按零计算。

暂不支持

  • Cursor：它会让自定义接口的流量经过它自己的服务器，而那些服务器连不到本地地址。
  • ChatGPT 应用：它不能使用自定义接口。
  • 图片编辑、音频翻译、实时语音。
  • Codex 的已连接应用（MCP）工具和网页搜索不会传给免费模型：它们带来的上下文比免费模型能接受的更多。
