下载

FreeAITokens 应用免费且开源。它运行在你自己的电脑上，常驻在菜单栏或系统托盘里。

下载适用于你电脑的版本

支持 Mac、Windows 和 Linux · 免费且开源

所有下载

  • Mac · Apple 芯片和 Intel，macOS 12 或更新版本.dmg · .zip
  • Windows · Windows 10 或 11安装程序 (.exe)
  • Linux · AppImage 或 Debian/Ubuntu 安装包AppImage · .deb · ARM AppImage · ARM .deb

旧版本和更新说明在 GitHub 上。

或者用一行命令安装

Mac 或 Linux：打开 Terminal，粘贴下面的命令，按 Return 键。

curl -fsSL https://{{domain}}/install | sh

Windows：打开 PowerShell，粘贴下面的命令，按 Enter 键。

irm https://{{domain}}/install.ps1 | iex

这些脚本逐行都做了什么。

第一次打开

这个应用目前还没有代码签名（签名每年都要花钱）。你的电脑会对来自它不认识的开发者的应用发出警告。想继续打开，请这样做：

Mac

  1. 打开应用。macOS 会提示无法验证它；点击完成。
  2. 打开系统设置 → 隐私与安全性，向下滚动，点击 FreeAITokens 旁边的仍要打开。
  3. 用你的密码或触控 ID 确认。只需要做这一次。

如果你是用 Terminal 里的那行命令安装的，就不需要这一步。

Windows

  1. 运行安装程序。如果出现蓝色的“Windows 已保护你的电脑”窗口，点击更多信息。
  2. 点击仍要运行。

Linux

让 AppImage 可以运行（右键 → 属性 → 允许执行，或用 chmod +x），然后打开它。有些系统还需要 libfuse2（Ubuntu 24.04 及更新版本上是 libfuse2t64）。

更喜欢命令行？

开发者可以跳过应用，在装有 Node.js 20 或更新版本的电脑上直接运行 npx freeaitokens。详见文档。
