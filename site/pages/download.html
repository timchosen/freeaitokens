Or install with one line

Mac or Linux: open Terminal, paste this, press Return.

curl -fsSL https://freeaitokens.co/install | sh

Windows: open PowerShell, paste this, press Enter.

irm https://freeaitokens.co/install.ps1 | iex

Opening it the first time

The app is not code-signed yet (signing costs money every year). Your computer warns you about apps from developers it doesn't know. To open it anyway:

Mac

  1. Open the app. macOS says it can't check it; click Done.
  2. Open System Settings → Privacy & Security, scroll down, and click Open Anyway next to FreeAITokens.
  3. Confirm with your password or Touch ID. You only do this once.

If you installed with the Terminal line, you skip this step.

Windows

  1. Run the installer. If a blue "Windows protected your PC" box appears, click More info.
  2. Click Run anyway.

Linux

Make the AppImage runnable (right-click → Properties → Allow executing, or chmod +x) and open it. Some systems also need libfuse2.

Prefer the command line?

Developers can skip the app and run npx freeaitokens with Node.js 20 or newer. See the docs.
