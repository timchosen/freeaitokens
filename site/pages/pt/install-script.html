O que o script de instalação faz

Colar no Terminal um comando tirado de um site significa confiar nesse site. Aqui está tudo o que o instalador do FreeAITokens faz, com o código completo.

Em palavras simples

  1. Descobre se você tem um Mac, um Linux ou um Windows.
  2. Baixa o app FreeAITokens mais recente das versões públicas no GitHub.
  3. Mac: coloca o app na pasta Aplicativos (trocando uma cópia mais antiga) e o abre. Linux: salva em ~/.local/bin/freeaitokens-app. Windows: executa o instalador normal.
  4. Apaga o arquivo baixado. Não muda mais nada: sem senha de administrador, sem configurações, sem outros programas.

O script inteiro fica dentro de uma única função que só roda no final, então um download interrompido no meio não faz nada.

Para ler antes de executar: curl -fsSL https://{{domain}}/install | less
