Configuração

Dois passos: adicione algumas chaves grátis e depois aponte sua ferramenta de IA para o FreeAITokens.

1. Adicione chaves grátis

{{keyless}} provedores funcionam sem nenhuma conta. Cada conta grátis que você adiciona aumenta o seu total.

  1. Clique no ícone do FreeAITokens na barra de menus ou na bandeja do sistema e escolha Add a provider (Adicionar um provedor).
  2. Escolha um provedor. O app abre a página de cadastro dele e diz exatamente onde clicar.
  3. Crie uma conta grátis, copie a chave que ele der e cole no app. O app confere a chave antes de salvar.

Boas opções para começar: Cerebras e Groq (cotas grátis grandes), OpenRouter (conecta com um clique) e Google Gemini.

As chaves ficam no seu computador, no chaveiro dele quando houver, e só são enviadas ao provedor a que pertencem. Use as suas próprias contas, uma por provedor. Por que isso importa.

2. Conecte sua ferramenta

Seu endereço local é http://127.0.0.1:4949. O menu do app tem Copy endpoint (Copiar endereço) e Copy local token (Copiar token local) para tudo o que pedir.

Claude Code

Inicie-o pelo FreeAITokens:

npx freeaitokens claude

Só essa sessão usa modelos grátis; rode claude normalmente para usar a sua própria conta.

Codex

npx freeaitokens codex

Gemini CLI

npx freeaitokens gemini

OpenCode

npx freeaitokens setup opencode

Depois escolha o modelo freeaitokens/free. O --undo restaura suas configurações antigas.

VS Code, Zed, JetBrains

Mostra exatamente o que colar nas configurações do editor:

npx freeaitokens setup vscode

Use zed ou jetbrains no lugar de vscode.

Cline, Continue, Roo Code, Crush

npx freeaitokens setup cline

Ou o nome da própria ferramenta no lugar de cline.

Kilo Code, Qwen Code, Goose, Aider

npx freeaitokens aider

Ou kilo, qwen, goose.

Qualquer outro app

Se ele permite definir um endereço OpenAI personalizado:

  • URL base http://127.0.0.1:4949/v1
  • Modelo free
  • Chave de API: Copy local token (Copiar token local) no menu do app

Os comandos acima precisam do Node.js. Se você não o tem, peça à sua IA para fazer essa parte, ou baixe o Node.js em nodejs.org.

Não suportado

O Cursor envia endereços personalizados pelos próprios servidores, que não alcançam o seu computador. O app do ChatGPT não consegue usar um endereço personalizado de jeito nenhum.
