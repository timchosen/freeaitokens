इंस्टॉल स्क्रिप्ट क्या करती है

किसी वेबसाइट से कमांड कॉपी करके Terminal में पेस्ट करने का मतलब उस वेबसाइट पर भरोसा करना है। यहाँ वह सब है जो FreeAITokens का इंस्टॉलर करता है, और उसका पूरा सोर्स।

आसान शब्दों में

  1. पता लगाती है कि आपके पास Mac, Linux या Windows कंप्यूटर है।
  2. FreeAITokens का नया ऐप उसके सार्वजनिक GitHub रिलीज़ से डाउनलोड करती है।
  3. Mac: ऐप को आपके Applications फ़ोल्डर में रखती है (पुरानी कॉपी बदलकर) और खोल देती है। Linux: इसे ~/.local/bin/freeaitokens-app के रूप में सेव करती है। Windows: सामान्य इंस्टॉलर चलाती है।
  4. डाउनलोड की हुई फ़ाइल मिटा देती है। इसके अलावा कुछ नहीं बदलती: न एडमिन पासवर्ड, न सेटिंग, न कोई दूसरा सॉफ़्टवेयर।

पूरी स्क्रिप्ट एक फ़ंक्शन के अंदर है जो बिल्कुल आख़िर में चलता है, इसलिए अगर डाउनलोड बीच में कट जाए तो कुछ नहीं होता।
