डाउनलोड

FreeAITokens ऐप मुफ़्त और ओपन सोर्स है। यह आपके अपने कंप्यूटर पर चलता है और आपके मेन्यू बार या सिस्टम ट्रे में दिखता है।

अपने कंप्यूटर के लिए डाउनलोड करें

Mac, Windows और Linux के लिए · मुफ़्त और ओपन सोर्स

सभी डाउनलोड

  • Mac · Apple silicon और Intel, macOS 12 या नया.dmg · .zip
  • Windows · Windows 10 या 11इंस्टॉलर (.exe)
  • Linux · AppImage या Debian/Ubuntu पैकेजAppImage · .deb · ARM AppImage · ARM .deb

पुराने वर्शन और रिलीज़ नोट्स GitHub पर हैं।

या एक लाइन से इंस्टॉल करें

Mac या Linux: Terminal खोलें, यह पेस्ट करें, Return दबाएँ।

curl -fsSL https://{{domain}}/install | sh

Windows: PowerShell खोलें, यह पेस्ट करें, Enter दबाएँ।

irm https://{{domain}}/install.ps1 | iex

ये स्क्रिप्ट क्या करती हैं, लाइन-दर-लाइन।

पहली बार खोलना

ऐप अभी कोड-साइन्ड नहीं है (साइनिंग का खर्च हर साल लगता है)। आपका कंप्यूटर ऐसे डेवलपर के ऐप के बारे में चेतावनी देता है जिन्हें वह नहीं जानता। फिर भी इसे खोलने के लिए:

Mac

  1. ऐप खोलें। macOS कहेगा कि वह इसे जाँच नहीं सकता; Done पर क्लिक करें।
  2. System Settings → Privacy & Security खोलें, नीचे स्क्रॉल करें, और FreeAITokens के आगे Open Anyway पर क्लिक करें।
  3. अपने पासवर्ड या Touch ID से पुष्टि करें। यह सिर्फ़ एक बार करना होता है।

अगर आपने Terminal वाली लाइन से इंस्टॉल किया है, तो यह कदम छूट जाता है।

Windows

  1. इंस्टॉलर चलाएँ। अगर नीला "Windows protected your PC" बॉक्स दिखे, तो More info पर क्लिक करें।
  2. Run anyway पर क्लिक करें।

Linux

AppImage को चलने लायक बनाएँ (राइट-क्लिक → Properties → Allow executing, या chmod +x) और खोलें। कुछ सिस्टम को libfuse2 भी चाहिए होता है (Ubuntu 24.04 और नए में libfuse2t64)।
