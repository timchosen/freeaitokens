सेटअप

सिर्फ़ दो कदम: कुछ मुफ़्त keys जोड़ें, फिर अपने AI टूल को FreeAITokens की तरफ़ मोड़ दें।

1. मुफ़्त keys जोड़ें

{{keyless}} प्रोवाइडर बिना किसी अकाउंट के काम करते हैं। आप जो भी मुफ़्त अकाउंट जोड़ते हैं, आपका कुल कोटा बढ़ जाता है।

  1. अपने मेन्यू बार या सिस्टम ट्रे में FreeAITokens के आइकन पर क्लिक करें और Add a provider (प्रोवाइडर जोड़ें) चुनें।
  2. कोई प्रोवाइडर चुनें। ऐप उसका साइन-अप पेज खोल देता है और बताता है कि ठीक-ठीक कहाँ क्लिक करना है।
  3. मुफ़्त अकाउंट बनाएँ, जो key मिले उसे कॉपी करें और ऐप में पेस्ट कर दें। सेव करने से पहले ऐप key को जाँच लेता है।

शुरू करने के लिए अच्छे विकल्प: Cerebras और Groq (बड़ा मुफ़्त कोटा), OpenRouter (एक क्लिक में कनेक्ट) और Google Gemini।

Keys आपके कंप्यूटर पर रहती हैं, जहाँ कीचेन हो वहाँ उसमें, और सिर्फ़ उसी प्रोवाइडर को भेजी जाती हैं जिसकी वे हैं। अपने ही अकाउंट इस्तेमाल करें, हर प्रोवाइडर पर एक। यह क्यों ज़रूरी है।

2. अपना टूल जोड़ें

आपका लोकल एड्रेस http://127.0.0.1:4949 है। जहाँ भी ज़रूरत हो, ऐप के मेन्यू में Copy endpoint और Copy local token मिलेंगे।

Claude Code

इसे FreeAITokens के ज़रिए शुरू करें:

npx freeaitokens claude

सिर्फ़ वही सेशन मुफ़्त मॉडल इस्तेमाल करता है; अपने अकाउंट के लिए claude सामान्य तरीके से चलाएँ।

Codex

npx freeaitokens codex

Gemini CLI

npx freeaitokens gemini

OpenCode

npx freeaitokens setup opencode

फिर मॉडल freeaitokens/free चुनें। --undo से आपकी पुरानी सेटिंग वापस आ जाती हैं।

VS Code, Zed, JetBrains

एडिटर की सेटिंग में क्या पेस्ट करना है, यह ठीक-ठीक छाप देता है:

npx freeaitokens setup vscode

vscode की जगह zed या jetbrains लिखें।

Cline, Continue, Roo Code, Crush

npx freeaitokens setup cline

या cline की जगह उस टूल का अपना नाम।

Kilo Code, Qwen Code, Goose, Aider

npx freeaitokens aider

या kilo, qwen, goose।

कोई दूसरा ऐप

अगर उसमें अपना OpenAI एड्रेस डालने की सुविधा है:

  • Base URL http://127.0.0.1:4949/v1
  • Model free
  • API key: ऐप के मेन्यू में Copy local token

ऊपर के कमांड के लिए Node.js चाहिए। अगर वह आपके पास नहीं है, तो यह हिस्सा अपने AI से करवाएँ, या Node.js nodejs.org से लें।

सपोर्ट नहीं है

Cursor कस्टम एड्रेस को अपने सर्वर से होकर भेजता है, जो आपके कंप्यूटर तक नहीं पहुँच सकते। ChatGPT ऐप कोई कस्टम एड्रेस इस्तेमाल ही नहीं कर सकता।
