Kommandozeile

Mit Node.js 20 oder neuer brauchst du die App nicht:

npx freeaitokens               # start the local endpoint
npx freeaitokens add           # add a free provider key (guided)
npx freeaitokens list          # providers, key status, what is left today
npx freeaitokens remove <id>   # delete a stored key

Oder installiere es einmalig: npm install -g freeaitokens. Der Endpunkt lauscht nur auf 127.0.0.1:4949 und braucht das lokale Token aus dem Startbanner. App und Befehl teilen sich Schlüssel und Einstellungen.

Die Starter wirken sich nur auf diese eine Sitzung aus und schreiben nichts in die Konfiguration deines Tools. setup opencode fügt einen Anbieter neben deinen bestehenden hinzu und legt eine Sicherung an; --undo stellt sie wieder her.

Was es tut

  • Wählt pro Anfrage ein Modell. Nur Modelle, die sie bewältigen können: genug Kontext, Tool-Aufrufe, wenn das Tool sie braucht, Bildverständnis, wenn Bilder dabei sind. Es bevorzugt bessere Modelle, die für dich schnell und zuverlässig waren, und bleibt während einer Unterhaltung beim selben Modell, solange kein anderes deutlich besser ist.
  • Weicht aus. Bei einem Ratenlimit, Serverfehler oder Timeout versucht es das nächste Modell, bevor dein Tool etwas davon merkt. Wenn alles ausgelastet ist und innerhalb von 30 Sekunden wieder Kapazität frei wird, wartet es; sonst sagt es dir, wann.
  • Verfolgt die kostenlosen Limits pro Anbieter, Modell und Schlüssel, pro Minute und pro Tag, und korrigiert sich anhand der Limits, die die Anbieter melden.
  • Spricht fünf Formate: OpenAI Chat Completions, Anthropic Messages (Claude Code), OpenAI Responses (Codex), Gemini (Gemini CLI) und Ollama (/api/chat).
  • Hält die Anbieterliste aktuell, signiert und vor der Nutzung geprüft, sodass neue kostenlose Modelle ohne Update ankommen.

Nicht nur Chat

Derselbe Endpunkt nimmt die OpenAI-Routen für Embeddings (/v1/embeddings), einfache Completions (/v1/completions), Bilder (/v1/images/generations), Text zu Sprache (/v1/audio/speech), Transkription (/v1/audio/transcriptions) und Video (/v1/videos) an. Jede geht an einen kostenlosen Anbieter, der sie anbietet, mit demselben Ausweichen und denselben Limits.

  • Heute kostenlos: Embeddings (Gemini, OpenRouter, SEA-LION, Cloudflare, OVH), Completions (Cerebras, OpenRouter, OVH), Bilder (Cloudflare Flux, OpenRouter), Text zu Sprache (Groq, OpenRouter, Cloudflare), Transkription (Groq, Cloudflare, OVH). Kostenloses Video bietet noch kein Anbieter an.
  • Embeddings: Vektoren verschiedener Modelle lassen sich nicht vergleichen. Sende den Modellnamen, den die Antwort dir genannt hat (zum Beispiel gemini-embedding-001), dann bleiben spätere Anfragen bei diesem Modell.

Bezahlte Schlüssel und Optionen

Bezahlte Schlüssel können als letzter Ausweg unter den kostenlosen stehen: Sie werden nur genutzt, wenn kein kostenloses Modell die Anfrage bedienen kann, jede bezahlte Anfrage wird ausgegeben, und es gibt eine Tagesobergrenze.

OptionWas sie tut
--port <n>Port für den lokalen Endpunkt (Standard 4949)
--free-onlyNie bezahlte Schlüssel verwenden
--paid-cap <n>Höchstzahl bezahlter Anfragen pro Tag (Standard 200)

Alle {{providers}} Anbieter

Zusammen veröffentlichen sie bis zu {{monthly}} kostenlose Tokens pro Monat. Diese Zahl addiert die veröffentlichten kostenlosen Limits und rechnet 2.000 Tokens pro Anfrage, wo nur ein Anfragelimit veröffentlicht ist; das meiste stammt aus wenigen großen Kontingenten, und du bekommst es nur mit einem Schlüssel für jeden Anbieter. Anbieter, die kein Limit veröffentlichen, zählen als null.

Noch nicht unterstützt

  • Cursor: Es schickt den Datenverkehr eigener Endpunkte über seine eigenen Server, die eine lokale Adresse nicht erreichen können.
  • Die ChatGPT-App: Sie kann keinen eigenen Endpunkt verwenden.
  • Bildbearbeitung, Audio-Übersetzung, Echtzeit-Sprache.
  • Die Tools für verbundene Apps (MCP) und die Websuche von Codex werden nicht an kostenlose Modelle weitergegeben: Sie bringen mehr Kontext mit, als kostenlose Modelle annehmen.
