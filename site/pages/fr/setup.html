Installation

Deux étapes : ajoutez quelques clés gratuites, puis dirigez votre outil d'IA vers FreeAITokens.

1. Ajoutez des clés gratuites

{{keyless}} fournisseurs fonctionnent sans aucun compte. Chaque compte gratuit que vous ajoutez augmente votre total.

  1. Cliquez sur l'icône FreeAITokens dans votre barre des menus ou votre zone de notification et choisissez Add a provider (Ajouter un fournisseur).
  2. Choisissez un fournisseur. L'app ouvre sa page d'inscription et vous dit exactement sur quoi cliquer.
  3. Créez un compte gratuit, copiez la clé qu'il vous donne et collez-la dans l'app. L'app vérifie la clé avant de l'enregistrer.

Bons fournisseurs pour commencer : Cerebras et Groq (de grosses parts gratuites), OpenRouter (connexion en un clic) et Google Gemini.

Les clés restent sur votre ordinateur, dans son trousseau quand il en a un, et ne sont jamais envoyées qu'au fournisseur auquel elles appartiennent. Utilisez vos propres comptes, un par fournisseur. Pourquoi c'est important.

2. Connectez votre outil

Votre adresse locale est http://127.0.0.1:4949. Le menu de l'app propose Copy endpoint (Copier l'adresse) et Copy local token (Copier le jeton local) pour tout ce qui les demande.

Claude Code

Lancez-le via FreeAITokens :

npx freeaitokens claude

Seule cette session utilise des modèles gratuits ; lancez claude normalement pour votre propre compte.

Codex

npx freeaitokens codex

Gemini CLI

npx freeaitokens gemini

OpenCode

npx freeaitokens setup opencode

Choisissez ensuite le modèle freeaitokens/free. --undo rétablit vos anciens réglages.

VS Code, Zed, JetBrains

Affiche exactement ce qu'il faut coller dans les réglages de l'éditeur :

npx freeaitokens setup vscode

Utilisez zed ou jetbrains à la place de vscode.

Cline, Continue, Roo Code, Crush

npx freeaitokens setup cline

Ou le nom de l'outil à la place de cline.

Kilo Code, Qwen Code, Goose, Aider

npx freeaitokens aider

Ou kilo, qwen, goose.

Toute autre app

Si elle permet de définir une adresse OpenAI personnalisée :

  • URL de base http://127.0.0.1:4949/v1
  • Modèle free
  • Clé API : Copy local token dans le menu de l'app

Les commandes ci-dessus demandent Node.js. Si vous ne l'avez pas, demandez à votre IA de s'occuper de cette partie, ou récupérez Node.js sur nodejs.org.

Pas pris en charge

Cursor fait passer les adresses personnalisées par ses propres serveurs, qui ne peuvent pas atteindre votre ordinateur. L'app ChatGPT ne peut pas du tout utiliser d'adresse personnalisée.
