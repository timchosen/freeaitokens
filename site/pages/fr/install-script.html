Ce que fait le script d'installation

Coller dans Terminal une commande trouvée sur un site, c'est faire confiance à ce site. Voici tout ce que fait l'installateur de FreeAITokens, avec son code complet.

En clair

  1. Détermine si vous avez un Mac, un ordinateur Linux ou Windows.
  2. Télécharge la dernière app FreeAITokens depuis ses versions publiques sur GitHub.
  3. Mac : place l'app dans votre dossier Applications (en remplaçant une ancienne copie) et l'ouvre. Linux : l'enregistre sous ~/.local/bin/freeaitokens-app. Windows : lance l'installateur habituel.
  4. Supprime le fichier téléchargé. Il ne change rien d'autre : pas de mot de passe administrateur, pas de réglages, pas d'autre logiciel.

Tout le script tient dans une seule fonction qui ne s'exécute qu'à la toute fin, donc un téléchargement coupé en route ne fait rien.

Pour le lire avant de l'exécuter : curl -fsSL https://{{domain}}/install | less
