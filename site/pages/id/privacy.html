Privasi

Ini terjemahan untuk memudahkan. Jika berbeda dengan versi bahasa Inggris, maka versi bahasa Inggris yang berlaku.

Singkatnya: FreeAITokens tidak mengumpulkan apa pun tentangmu. Sinkronisasi berbayar opsional hanya menyimpan data terenkripsi yang tidak bisa dibacanya.

Situs web ini

  • Tanpa cookie, tanpa analitik, tanpa iklan, tanpa skrip pelacak.
  • Situs ini dihosting di Cloudflare, yang mengurus koneksi dan menyimpan log teknis standar (seperti alamat IP) untuk menjalankan dan melindungi layanan.
  • Halaman-halaman meminta jumlah bintang proyek dari GitHub, jadi GitHub melihat permintaan itu dari browsermu.

Aplikasi dan perintahnya

  • Kunci-kuncimu tetap di komputermu, di keychain bila ada, dan hanya dikirim ke penyedia pemiliknya.
  • Prompt dan jawabanmu langsung berpindah antara komputermu dan penyedia AI. Semuanya tidak pernah melewati server FreeAITokens. Apa yang dilakukan tiap penyedia dengan data itu diatur oleh kebijakan privasinya sendiri; penyedia yang mungkin memakainya untuk pelatihan diberi tanda. Jika Anda menyalakan sinkronisasi, obrolan tersimpan Anda juga disimpan terenkripsi, seperti dijelaskan di bawah.
  • Daftar penyedia diunduh beberapa kali sehari dari layanan FreeAITokens di Cloudflare. Permintaan itu tidak berisi apa pun tentangmu atau cara kamu memakainya; seperti permintaan web pada umumnya, ia memperlihatkan alamat IP-mu kepada Cloudflare.
  • Tanpa telemetri. Aplikasi tidak melaporkan pemakaian, error, atau apa pun lainnya.
  • Alamat lokal hanya mendengarkan di komputermu sendiri dan membutuhkan token, sehingga perangkat dan situs web lain tidak bisa memakainya.

Sinkronisasi (opsional, berbayar)

Jika Anda membeli sinkronisasi, server FreeAITokens di Cloudflare menyimpan:

  • Obrolan dan kunci Anda, terenkripsi di komputer Anda sebelum dikirim. Server tidak pernah memegang frasa sandi Anda atau kunci yang membukanya, jadi tidak bisa membacanya.
  • Untuk setiap item yang disinkronkan: id acak, ukurannya, nomor versi, dan kapan berubah.
  • Bentuk acak (hash) dari kunci sinkronisasi Anda, tidak pernah kuncinya sendiri.
  • Bentuk acak (hash berkunci) dari email yang Anda pakai membayar, hanya agar formulir "kirimi saya kunci" bisa menemukan kunci Anda. Emailnya sendiri tidak disimpan.
  • Paket Anda, kapan berakhir, dan id Stripe untuk pembayaran serta catatan pelanggan Anda.

Stripe menjual sinkronisasi dan menerima pembayarannya, jadi detail pembayaran dan email Anda dikirim ke Stripe sesuai kebijakan privasinya. Saat paket berakhir, atau pembayaran dikembalikan atau disengketakan, data terenkripsi Anda dihapus 90 hari kemudian.
