Privasi

Ini terjemahan untuk memudahkan. Jika berbeda dengan versi bahasa Inggris, maka versi bahasa Inggris yang berlaku.

Singkatnya: FreeAITokens tidak mengumpulkan apa pun tentangmu.

Situs web ini

  • Tanpa cookie, tanpa analitik, tanpa iklan, tanpa skrip pelacak.
  • Situs ini dihosting di Cloudflare, yang mengurus koneksi dan menyimpan log teknis standar (seperti alamat IP) untuk menjalankan dan melindungi layanan.
  • Halaman-halaman meminta jumlah bintang proyek dari GitHub, jadi GitHub melihat permintaan itu dari browsermu.

Aplikasi dan perintahnya

  • Kunci-kuncimu tetap di komputermu, di keychain bila ada, dan hanya dikirim ke penyedia pemiliknya.
  • Prompt dan jawabanmu langsung berpindah antara komputermu dan penyedia AI. Semuanya tidak pernah melewati server FreeAITokens. Apa yang dilakukan tiap penyedia dengan data itu diatur oleh kebijakan privasinya sendiri; penyedia yang mungkin memakainya untuk pelatihan diberi tanda.
  • Daftar penyedia diunduh beberapa kali sehari dari layanan FreeAITokens di Cloudflare. Permintaan itu tidak berisi apa pun tentangmu atau cara kamu memakainya; seperti permintaan web pada umumnya, ia memperlihatkan alamat IP-mu kepada Cloudflare.
  • Tanpa telemetri. Aplikasi tidak melaporkan pemakaian, error, atau apa pun lainnya.
  • Alamat lokal hanya mendengarkan di komputermu sendiri dan membutuhkan token, sehingga perangkat dan situs web lain tidak bisa memakainya.

Pertanyaan

Tanyakan di GitHub, atau laporkan masalah keamanan secara pribadi.
