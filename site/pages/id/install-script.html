Apa yang dilakukan skrip instalasi

Menempelkan perintah dari sebuah situs web ke Terminal berarti memercayai situs itu. Berikut semua yang dilakukan pemasang FreeAITokens, beserta kode sumber lengkapnya.

Dengan kata sederhana

  1. Mencari tahu apakah komputermu Mac, Linux, atau Windows.
  2. Mengunduh aplikasi FreeAITokens terbaru dari rilis GitHub publiknya.
  3. Mac: menaruh aplikasi di folder Applications (menggantikan salinan lama) lalu membukanya. Linux: menyimpannya sebagai ~/.local/bin/freeaitokens-app. Windows: menjalankan pemasang biasa.
  4. Menghapus berkas yang diunduh. Tidak ada hal lain yang diubah: tanpa kata sandi admin, tanpa pengaturan, tanpa perangkat lunak lain.

Seluruh skrip berada di dalam satu fungsi yang baru dijalankan di paling akhir, jadi unduhan yang terputus di tengah tidak melakukan apa-apa.

Untuk membacanya sebelum menjalankan: curl -fsSL https://{{domain}}/install | less

Mac dan Linux: /install

{{installScript}}

Windows: /install.ps1

{{installPs1}}
