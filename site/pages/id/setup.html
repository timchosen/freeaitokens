Pengaturan

Dua langkah: tambahkan beberapa kunci gratis, lalu arahkan alat AI-mu ke FreeAITokens.

1. Tambahkan kunci gratis

{{keyless}} penyedia bisa dipakai tanpa akun sama sekali. Setiap akun gratis yang kamu tambahkan menaikkan totalmu.

  1. Klik ikon FreeAITokens di menu bar atau system tray, lalu pilih Add a provider (Tambah penyedia).
  2. Pilih sebuah penyedia. Aplikasi membuka halaman pendaftarannya dan memberi tahu persis apa yang perlu diklik.
  3. Buat akun gratis, salin kunci yang diberikan, lalu tempel ke aplikasi. Aplikasi memeriksa kunci itu sebelum menyimpannya.

Yang bagus untuk memulai: Cerebras dan Groq (jatah gratis besar), OpenRouter (tersambung dengan satu klik), dan Google Gemini.

Kunci tetap di komputermu, di keychain bila ada, dan hanya dikirim ke penyedia pemiliknya. Pakai akunmu sendiri, satu per penyedia. Kenapa itu penting.

2. Sambungkan alatmu

Alamat lokalmu adalah http://127.0.0.1:4949. Menu aplikasi punya Copy endpoint dan Copy local token untuk apa pun yang memintanya.

Claude Code

Jalankan lewat FreeAITokens:

npx freeaitokens claude

Hanya sesi itu yang memakai model gratis; jalankan claude seperti biasa untuk akunmu sendiri.

Codex

npx freeaitokens codex

Gemini CLI

npx freeaitokens gemini

OpenCode

npx freeaitokens setup opencode

Lalu pilih model freeaitokens/free. --undo mengembalikan pengaturan lamamu.

VS Code, Zed, JetBrains

Menampilkan persis apa yang perlu ditempel ke pengaturan editor:

npx freeaitokens setup vscode

Pakai zed atau jetbrains sebagai ganti vscode.

Cline, Continue, Roo Code, Crush

npx freeaitokens setup cline

Atau nama alatnya sendiri sebagai ganti cline.

Kilo Code, Qwen Code, Goose, Aider

npx freeaitokens aider

Atau kilo, qwen, goose.

Aplikasi lain

Kalau aplikasinya memungkinkan mengatur alamat OpenAI khusus:

  • Base URL http://127.0.0.1:4949/v1
  • Model free
  • Kunci API: Copy local token di menu aplikasi

Perintah di atas membutuhkan Node.js. Kalau belum punya, minta AI-mu mengerjakan bagian ini, atau ambil Node.js dari nodejs.org.

Belum didukung

Cursor mengirim alamat khusus lewat servernya sendiri, yang tidak bisa menjangkau komputermu. Aplikasi ChatGPT sama sekali tidak bisa memakai alamat khusus.
