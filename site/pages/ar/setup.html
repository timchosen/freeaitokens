الإعداد

خطوتان: أضف بضعة مفاتيح مجانية، ثم وجّه أداتك الذكية إلى FreeAITokens.

1. أضف مفاتيح مجانية

يعمل {{keyless}} مزوِّدين دون أي حساب. وكل حساب مجاني تضيفه يرفع رصيدك الإجمالي.

  1. اضغط على أيقونة FreeAITokens في شريط القوائم أو منطقة إشعارات النظام، واختر Add a provider (إضافة مزوِّد).
  2. اختر مزوِّدًا. يفتح التطبيق صفحة التسجيل الخاصة به ويخبرك بالضبط على ماذا تضغط.
  3. أنشئ حسابًا مجانيًا، وانسخ المفتاح الذي يعطيك إياه، والصقه في التطبيق. يتحقق التطبيق من المفتاح قبل حفظه.

بداية جيدة: Cerebras وGroq (أرصدة مجانية كبيرة)، وOpenRouter (يتصل بنقرة واحدة)، وGoogle Gemini.

تبقى المفاتيح على جهازك، في سلسلة المفاتيح (keychain) إن وُجدت، ولا تُرسل إلا إلى المزوِّد الذي تخصّه. استخدم حساباتك أنت، حسابًا واحدًا لكل مزوِّد. لماذا هذا مهم.

2. اربط أداتك

عنوانك المحلي هو http://127.0.0.1:4949. في قائمة التطبيق Copy endpoint (نسخ العنوان) وCopy local token (نسخ الرمز المحلي) لأي شيء يطلبهما.

Claude Code

شغّله عبر FreeAITokens:

npx freeaitokens claude

هذه الجلسة وحدها تستخدم النماذج المجانية؛ شغّل claude كالمعتاد لاستخدام حسابك الخاص.

Codex

npx freeaitokens codex

Gemini CLI

npx freeaitokens gemini

OpenCode

npx freeaitokens setup opencode

ثم اختر النموذج freeaitokens/free. ويعيد --undo إعداداتك القديمة.

VS Code وZed وJetBrains

يطبع بالضبط ما يجب لصقه في إعدادات المحرر:

npx freeaitokens setup vscode

استخدم zed أو jetbrains بدلًا من vscode.

Cline وContinue وRoo Code وCrush

npx freeaitokens setup cline

أو اسم الأداة نفسها بدلًا من cline.

Kilo Code وQwen Code وGoose وAider

npx freeaitokens aider

أو kilo أو qwen أو goose.

أي تطبيق آخر

إذا كان يتيح لك تحديد عنوان OpenAI مخصص:

  • العنوان الأساسي http://127.0.0.1:4949/v1
  • النموذج free
  • مفتاح API: Copy local token (نسخ الرمز المحلي) من قائمة التطبيق

تحتاج الأوامر أعلاه إلى Node.js. إذا لم يكن لديك، اطلب من الذكاء الاصطناعي أن ينفّذ هذا الجزء، أو نزّل Node.js من nodejs.org.

غير مدعوم

يمرّر Cursor العناوين المخصصة عبر خوادمه، ولا تستطيع الوصول إلى جهازك. وتطبيق ChatGPT لا يستطيع استخدام عنوان مخصص إطلاقًا.
