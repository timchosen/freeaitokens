سطر الأوامر

مع Node.js 20 أو أحدث لا تحتاج إلى التطبيق:

npx freeaitokens               # start the local endpoint
npx freeaitokens add           # add a free provider key (guided)
npx freeaitokens list          # providers, key status, what is left today
npx freeaitokens remove <id>   # delete a stored key

أو ثبّته مرة واحدة: npm install -g freeaitokens. يستمع العنوان المحلي إلى 127.0.0.1:4949 فقط، ويحتاج إلى الرمز المحلي الظاهر في شاشة البدء. يتشارك التطبيق والأمر المفاتيح والإعدادات.

تؤثر أدوات التشغيل هذه في الجلسة الواحدة فقط ولا تكتب شيئًا في إعدادات أداتك. أما setup opencode فيضيف مزوِّدًا بجانب مزوِّديك الحاليين ويحتفظ بنسخة احتياطية؛ ويستعيدها --undo.

ماذا يفعل

  • يختار نموذجًا لكل طلب. فقط النماذج القادرة على تنفيذه: سياق كافٍ، واستدعاء الأدوات حين تحتاجه الأداة، وقراءة الصور حين توجد صور. يفضّل النماذج الأفضل التي كانت سريعة وموثوقة معك، ويبقى على النموذج نفسه خلال المحادثة ما لم يكن غيره أفضل بوضوح.
  • ينتقل عند الفشل. عند بلوغ حد الاستخدام أو خطأ في الخادم أو انتهاء المهلة يجرّب النموذج التالي قبل أن ترى أداتك شيئًا. وإذا كان كل شيء مشغولًا وستعود السعة خلال 30 ثانية فإنه ينتظر؛ وإلا يخبرك متى.
  • يتتبع الحدود المجانية لكل مزوِّد ونموذج ومفتاح، بالدقيقة وباليوم، ويصحّح نفسه من الحدود التي يبلغ بها المزوِّدون.
  • يتحدث خمس صيغ: OpenAI chat completions، وAnthropic Messages (لـ Claude Code)، وOpenAI Responses (لـ Codex)، وGemini (لـ Gemini CLI)، وOllama (/api/chat).
  • يحتفظ بقائمة مزوِّدين محدّثة، موقَّعة ويجري التحقق منها قبل الاستخدام، فتصل النماذج المجانية الجديدة دون تحديث.

ليس للمحادثة فقط

يقبل العنوان نفسه مسارات OpenAI الخاصة بالتضمينات (/v1/embeddings) والإكمال النصي العادي (/v1/completions) والصور (/v1/images/generations) وتحويل النص إلى كلام (/v1/audio/speech) وتفريغ الصوت إلى نص (/v1/audio/transcriptions) والفيديو (/v1/videos)، ويرسل كلًّا منها إلى مزوِّد مجاني يقدّمه، مع الانتقال عند الفشل والحدود نفسها.

  • مجاني اليوم: التضمينات (Gemini وOpenRouter وSEA-LION وCloudflare وOVH)، والإكمال النصي (Cerebras وOpenRouter وOVH)، والصور (Cloudflare Flux وOpenRouter)، وتحويل النص إلى كلام (Groq وOpenRouter وCloudflare)، وتفريغ الصوت (Groq وCloudflare وOVH). لا يقدّم أي مزوِّد فيديو مجانيًا حتى الآن.
  • التضمينات: لا يمكن مقارنة المتجهات الصادرة من نماذج مختلفة. أرسل اسم النموذج الذي أعطاك إياه الرد (مثل gemini-embedding-001) فتبقى الطلبات اللاحقة عليه.

المفاتيح المدفوعة والخيارات

يمكن وضع المفاتيح المدفوعة تحت المجانية كحل أخير: لا تُستخدم إلا حين لا يستطيع أي نموذج مجاني تلبية الطلب، ويُطبع كل طلب مدفوع، ضمن حد يومي.

الخيارماذا يفعل
--port <n>المنفذ الذي يستخدمه العنوان المحلي (الافتراضي 4949)
--free-onlyعدم استخدام المفاتيح المدفوعة إطلاقًا
--paid-cap <n>أقصى عدد من الطلبات المدفوعة في اليوم (الافتراضي 200)

غير مدعوم بعد

  • Cursor: يمرّر حركة العناوين المخصصة عبر خوادمه، ولا تستطيع الوصول إلى عنوان محلي.
  • تطبيق ChatGPT: لا يستطيع استخدام عنوان مخصص.
  • تعديل الصور، وترجمة الصوت، والصوت الفوري.
  • أدوات Codex للتطبيقات المتصلة (MCP) وبحث الويب لا تُمرَّر إلى النماذج المجانية: فهي تضيف سياقًا أكبر مما تقبله النماذج المجانية.
