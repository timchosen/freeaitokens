セットアップ

手順は2つです。無料キーをいくつか追加して、AIツールをFreeAITokensにつなぎます。

1. 無料キーを追加する

{{keyless}}社のプロバイダーは、アカウントなしでそのまま使えます。無料アカウントを追加するたびに、使える枠の合計が増えます。

  1. メニューバーまたはシステムトレイのFreeAITokensのアイコンをクリックし、Add a provider（プロバイダーを追加）を選びます。
  2. プロバイダーを選びます。アプリが登録ページを開き、何をクリックすればよいかを具体的に案内します。
  3. 無料アカウントを作り、発行されたキーをコピーして、アプリに貼り付けます。アプリは保存する前にキーを確認します。

最初におすすめなのは、CerebrasとGroq（無料枠が大きい）、OpenRouter（ワンクリックで接続）、Google Geminiです。

キーはあなたのパソコンに保存されます。キーチェーンがある環境ではキーチェーンに保存され、そのキーが属するプロバイダーにだけ送られます。プロバイダーごとに、自分のアカウントを1つ使ってください。これが大切な理由。

2. ツールを接続する

ローカルアドレスは http://127.0.0.1:4949 です。入力を求められたときのために、アプリのメニューにはCopy endpoint（エンドポイントをコピー）とCopy local token（ローカルトークンをコピー）があります。

Claude Code

FreeAITokens経由で起動します:

npx freeaitokens claude

無料モデルを使うのはそのセッションだけです。ご自分のアカウントで使うときは、いつもどおり claude を実行してください。

Codex

npx freeaitokens codex

Gemini CLI

npx freeaitokens gemini

OpenCode

npx freeaitokens setup opencode

そのあと、モデルに freeaitokens/free を選びます。--undo を付けると、元の設定に戻せます。

VS Code、Zed、JetBrains

エディターの設定に貼り付ける内容がそのまま表示されます:

npx freeaitokens setup vscode

vscode の代わりに zed または jetbrains を使ってください。

Cline、Continue、Roo Code、Crush

npx freeaitokens setup cline

cline の代わりに、そのツール自身の名前でも使えます。

Kilo Code、Qwen Code、Goose、Aider

npx freeaitokens aider

または kilo、qwen、goose。

そのほかのアプリ

カスタムのOpenAIアドレスを設定できるなら:

  • Base URL http://127.0.0.1:4949/v1
  • Model free
  • APIキー: アプリのメニューのCopy local token

上のコマンドにはNode.jsが必要です。入っていない場合は、この部分をAIに頼むか、nodejs.orgからNode.jsを入手してください。

対応していないもの

Cursorは、カスタムアドレスへのリクエストを自社のサーバー経由で送るため、あなたのパソコンには届きません。ChatGPTアプリは、カスタムアドレスをそもそも使えません。
