コマンドライン

Node.js 20以降があれば、アプリは不要です:

npx freeaitokens               # start the local endpoint
npx freeaitokens add           # add a free provider key (guided)
npx freeaitokens list          # providers, key status, what is left today
npx freeaitokens remove <id>   # delete a stored key

1回だけインストールして使うこともできます: npm install -g freeaitokens。エンドポイントは 127.0.0.1:4949 だけで待ち受け、起動時のバナーに表示されるローカルトークンが必要です。アプリとコマンドは、キーと設定を共有します。

ツールで使う

ツール方法
Claude Codenpx freeaitokens claude（続けてClaude Codeの引数も指定できます）
Codexnpx freeaitokens codex
Gemini CLInpx freeaitokens gemini

Kilo Code CLI、Qwen Code、Goose、Aidernpx freeaitokens kilo / qwen / goose / aider
Zed、JetBrains AI、VS Codenpx freeaitokens setup zed / jetbrains / vscode で、貼り付ける内容が表示されます
Continue、Cline、Crush、Roo Codenpx freeaitokens setup cline（またはそのツールの名前）で、設定値が表示されます
OpenAI互換のあらゆるものBase URL http://127.0.0.1:4949/v1、モデル free、キーは起動時のバナーに表示されたもの
Anthropic、Gemini、OllamaのクライアントBase URL http://127.0.0.1:4949、キーは同じもの

ランチャーが影響するのはそのセッションだけで、ツールの設定ファイルには何も書き込みません。setup opencode は、既存のプロバイダーの隣に新しいプロバイダーを追加し、バックアップを残します。--undo で元に戻せます。

できること

  • リクエストごとにモデルを選びます。対応できるモデルだけが対象です。十分なコンテキストがあること、ツールが必要ならツール呼び出しに対応していること、画像があるなら画像を読めることが条件です。あなたの環境で速く安定していた、より良いモデルを優先し、ほかのモデルが明らかに良くない限り、会話の途中では同じモデルを使い続けます。
  • 自動で切り替えます。上限、サーバーエラー、タイムアウトが起きたときは、ツールに何も見せる前に次のモデルを試します。すべてが混み合っていても、30秒以内に空きが戻るなら待ち、そうでなければいつ使えるかをお知らせします。
  • 無料の上限を記録します。プロバイダー、モデル、キーごとに、分単位と日単位で管理し、プロバイダーが返す上限の情報をもとに自分で補正します。
  • 5つの形式に対応します:OpenAI chat completions、Anthropic Messages（Claude Code）、OpenAI Responses（Codex）、Gemini（Gemini CLI）、Ollama（/api/chat）。
  • 最新のプロバイダー一覧を保ちます。一覧は署名され、使う前に検証されるので、アップデートなしで新しい無料モデルが追加されます。

チャット以外

同じエンドポイントで、埋め込み（/v1/embeddings）、通常の補完（/v1/completions）、画像（/v1/images/generations）、音声読み上げ（/v1/audio/speech）、文字起こし（/v1/audio/transcriptions）、動画（/v1/videos）のOpenAI形式のルートも使えます。それぞれ、対応する無料プロバイダーに送られ、同じ切り替えと上限管理が働きます。

  • 現在無料で使えるもの:埋め込み（Gemini、OpenRouter、SEA-LION、Cloudflare、OVH）、補完（Cerebras、OpenRouter、OVH）、画像（Cloudflare Flux、OpenRouter）、音声読み上げ（Groq、OpenRouter、Cloudflare）、文字起こし（Groq、Cloudflare、OVH）。無料で動画を提供しているプロバイダーは、まだありません。
  • 埋め込み:異なるモデルのベクトルどうしは比較できません。レスポンスで返されたモデル名（たとえば gemini-embedding-001）を指定すると、以降のリクエストも同じモデルを使います。

有料キーとオプション

有料キーは、無料キーの後ろに最後の手段として置けます。リクエストに応えられる無料モデルがないときだけ使われ、有料のリクエストはそのつど表示され、1日の上限もあります。

オプション内容
--port <n>ローカルエンドポイントのポート（初期値は4949）
--free-only有料キーを一切使いません
--paid-cap <n>1日あたりの有料リクエストの最大数（初期値は200）

{{providers}}社すべてのプロバイダー

すべて合わせると、毎月最大{{monthly}}の無料トークンが公開されています。この数字は、公表されている無料の上限を足し合わせたもので、リクエスト数の上限しか公表されていない場合は、1リクエストあたり2,000トークンとして数えています。大半は、いくつかの大きな無料枠によるもので、使えるのは各プロバイダーのキーを用意した場合だけです。上限を公表していないプロバイダーは、ゼロとして数えます。

まだ対応していないもの

  • Cursor:カスタムエンドポイントへの通信を自社のサーバー経由で行うため、ローカルアドレスには届きません。
  • ChatGPTアプリ:カスタムエンドポイントを使えません。
  • 画像の編集、音声の翻訳、リアルタイム音声。
  • Codexの連携アプリ（MCP）ツールとウェブ検索は、無料モデルには渡されません。無料モデルが受け付ける量より多くのコンテキストが増えてしまうためです。
