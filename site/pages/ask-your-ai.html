Ask your AI to set it up

If you use an AI assistant that can run commands on your computer, such as Claude Code, Claude's desktop app, Codex or ChatGPT's agent, it can do the whole setup for you.

Paste this to it:

Please set up FreeAITokens on my computer by following https://{{domain}}/setup.md

What it will do

  1. Install the FreeAITokens app.
  2. Ask which providers you want and open each sign-up page for you.
  3. Wait while you create the free accounts and copy the keys. It never types your passwords or creates accounts for you.
  4. Connect the AI tools you use, and check that everything works.

It explains each step before doing it, so you can stop it at any time.

What it reads

The instructions are a plain page written for AI assistants: {{domain}}/setup.md. You can read it yourself first.
